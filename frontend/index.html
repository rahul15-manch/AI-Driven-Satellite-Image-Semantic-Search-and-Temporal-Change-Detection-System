          Methodology, Hardware Constraints & Scientific Limitations

          Transparent documentation of experimental protocols, architectural choices, and honest disclosure of empirical constraints.

          1. Semantic Retrieval Formulation (M4)

          Cross-modal text-to-image retrieval maps natural language queries $q$ and aerial imagery $x$ into a shared 512-dimensional embedding space using OpenAI CLIP ViT-B/32. Vectors are $L_2$-normalized such that inner-product similarity corresponds strictly to cosine similarity.

          • Dataset: RSICD (Remote Sensing Image Captioning Dataset)
          • Test Gallery: 1,093 held-out test scenes
          • Indexing: FAISS-CPU IndexFlatIP (single-process CPU execution)
          • Domain Ensembling: 5 remote-sensing prompt templates averaged prior to normalization

          2. Bi-Temporal Change Detection Formulation (M5–M10)

          Given co-registered optical scenes $T_1, T_2 \in \mathbb{R}^{H \times W \times 3}$, models compute continuous change likelihoods $D(x, y) \in [0, 1]$, binarized at frozen validation threshold $\tau^*$:

          • B1 Pixel Difference: Absolute grayscale difference ($L_1$), $\tau^* = 0.4100$
          • B2 SSIM: Localized structural dissimilarity ($1 - \text{SSIM}$), $\tau^* = 0.9000$
          • B3 CVA: Radiometric change vector magnitude in spectral space, $\tau^* = 0.4050$
          • M7 FC-Siam-diff: Fully convolutional Siamese U-Net with feature differencing, $\tau^* = 0.5500$
          • M8 SNUNet-CD: Dense skip Siamese network with Ensemble Channel Attention, $\tau^* = 0.5000$
          • M9 BIT-CD: ResNet18 encoder with bitemporal transformer token exchange, $\tau^* = 0.4500$
          • M10 QAT-CD: Multi-signal quality gating attenuating registration and sharpness artifacts, $\tau^* = 0.4500$

          3. Hardware Constraints & Fair Profiling

          The entire research framework is constrained to commodity CPU hardware without cloud GPUs, CUDA, or distributed clusters:

          • Platform: Apple Silicon arm64 (8-core CPU), PyTorch 2.5.1 CPU
          • Thread Control: Strictly fixed at torch.set_num_threads(4)
          • Memory Ceiling: Peak RAM constrained under 8 GB (verified peak RSS: 877 MB)
          • Profiling Policy: 1 warm-up scene prior to timed runs; latency reported across mean, P50, and P95

          4. Scientific Limitations & Threats to Validity

          A. Closed-Benchmark Test Set Reuse: As recorded in the project devlog and decision logs, the official 128-scene LEVIR-CD test split has been evaluated repeatedly across milestones M5–M10. While decision thresholds were strictly calibrated on the 64 validation scenes, repeated inspection means test results represent a closed retrospective benchmark rather than an untouched prospective trial.

          B. QAT-CD Active Gating is Exploratory: Under validation calibration optimizing for unweighted F1, the optimal attenuation strength was $\gamma^* = 0.0$ (identical to BIT-CD). The active gating setting ($\gamma = 0.30$) suppresses 29.19% of false alarms and raises precision by +5.42 pp, but slightly reduces unweighted F1. It must not be claimed as an unconditional F1 improvement.

          C. SNUNet-CD False Alarms: Dense multi-scale feature concatenation without spatial boundary priors results in severe false-alarm runaway (over 53 million false-positive pixels), confirming that high recall alone is insufficient in aerial surveillance.
